# HikersClub

A full-stack web application for discovering, reviewing, and managing hiking destinations.

## Features
- User authentication and authorization
- Add, edit, and delete hiking locations
- Image upload support
- Reviews and ratings
- Interactive map/location support
- Server-side validation and error handling

## Tech Stack
- Node.js
- Express.js
- MongoDB
- EJS
- Cloudinary
- Mapbox
- Joi

## Why I built this
Built to practice full-stack backend architecture, authentication flows, CRUD design, schema validation, and media integration in a production-style web application.

## Architecture / Engineering Highlights
- Modular MVC-style structure using controllers, routes, models, and views
- Validation with Joi before persistence
- Middleware-based authentication and authorization
- Image/media handling with Cloudinary
- Reusable utilities and seed data support
